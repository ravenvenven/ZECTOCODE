Apa itu VS Code?
📖 Penjelasan Dasar

Visual Studio Code (VS Code) adalah editor teks gratis dan open-source yang dibuat oleh Microsoft. VS Code adalah salah satu editor paling populer di dunia karena:

  • Ringan dan cepat — tidak memberatkan laptop/komputer
  • Banyak ekstensi — support hampir semua bahasa pemrograman
  • Integrasi Git — version control langsung di editor
  • IntelliSense — fitur auto-complete yang cerdas
  • Terminal terintegrasi — jalankan perintah tanpa keluar editor

VS Code cocok untuk pemula karena mudah digunakan dan memiliki dukungan komunitas yang besar.

Cara Install VS Code
🛠️ Tutorial Step-by-Step
Kunjungi Website code.visualstudio.com
Langkah 1

Kunjungi Website Resmi

Buka code.visualstudio.com di browser kamu. Klik tombol "Download" yang sesuai dengan sistem operasi kamu (Windows, Mac, atau Linux).

Tips

Pastikan kamu mendownload versi Stable (bukan Insider) untuk penggunaan sehari-hari.

Jalankan Installer Klik Next → Next → Install
Langkah 2

Jalankan Installer

Buka file installer yang sudah di-download. Ikuti instruksi di layar — cukup klik "Next" sampai selesai. Centang opsi "Add to PATH" agar bisa dijalankan dari terminal.

Buka VS Code Start Menu / Applications
Langkah 3

Buka VS Code

Setelah install selesai, buka VS Code dari Start Menu (Windows) atau Applications (Mac). Kamu akan melihat tampilan awal selamat datang.

Install Bahasa Indonesia Opsional
Langkah 4

Install Bahasa Indonesia (Opsional)

Klik ikon Extensions (Ctrl+Shift+X) di sidebar kiri. Cari "Indonesian Language Pack" lalu klik "Install". Restart VS Code untuk melihat perubahan.

Tampilan VS Code
👀 Kenali Antar Muka
4 Bagian Utama VS Code Sidebar · Editor · Terminal · Status Bar

Explorer (Sidebar Kiri)

Menampilkan folder dan file yang sedang kamu buka. Di sinilah kamu mengelola project.

Editor (Tengah)

Area utama untuk menulis kode. Kamu bisa membuka banyak tab sekaligus.

Terminal (Bawah)

Jalankan perintah seperti npm, git, atau menjalankan program langsung di sini.

Extensions (Sidebar Kiri)

Cari dan install ekstensi untuk menambah fitur VS Code.

Ekstensi Wajib untuk Pemula
🧩 Rekomendasi Terbaik
Klik ikon Extensions di sidebar kiri

Prettier

Auto-format kode agar rapi dan konsisten. Cukup tekan Ctrl+Shift+I.

ESLint

Mendeteksi error dan bug di kode JavaScript-mu secara real-time.

Material Icon Theme

Memberikan ikon yang cantik untuk file dan folder di Explorer.

Live Server

Jalankan server lokal untuk melihat hasil HTML/CSS secara live.

Cara Install Ekstensi: Klik ikon di sidebar kiri → cari nama ekstensi → klik "Install".

Menulis Kode Pertama
📝 Praktik Langsung
Buat file index.html
1

Buat Folder Baru

Buat folder di komputer kamu, misal "BelajarHTML".

2

Buka Folder di VS Code

Klik File → Open Folder → pilih folder yang sudah dibuat.

3

Buat File HTML

Klik ikon file baru (atau Ctrl+N), simpan sebagai index.html.

4

Tulis Kode

Ketik html:5 lalu tekan Tab — VS Code akan membuat struktur HTML otomatis!

Contoh kode HTML sederhana:

index.html 
<!-- Ini adalah HTML dasar -->
<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Belajar VS Code</title>
</head>
<body>
    <h1>Halo, ini kode pertamaku!</h1>
    <p>Saya belajar coding dengan VS Code.</p>
</body>
</html>
Tips Penting

Ketik html:5 lalu tekan Tab — VS Code akan otomatis membuat struktur HTML lengkap! Ini disebut Emmet, fitur yang mempercepat penulisan kode.
